Spark SQL - A high-level API providing abstraction over RDDs for data processing

DataFrame - Immutable distributed collection of data organized into named columns

Spark Session - Entry point to programming with DataFrame and Dataset API

Infer Schema - Automatically infer the column data types in Spark from a given dataset

Print Schema - Method to print the schema of a DataFrame, showing column names and types

Catalyst Optimizer - Core optimization engine of Spark SQL, enhancing performance through query transformations

Tungsten Project - Spark's execution engine enhancement for better memory management and performance

Predicate Pushdown - Optimization technique where filter conditions are pushed to the data source

Broadcast Join - Join strategy for handling a small data set by copying it to all cluster nodes

Group By - Transform operation used to aggregate data based on column values

Show Action - Spark action to display top records of a DataFrame in a tabular format

Filter Transformation - Selective retrieval of rows that satisfy a given condition
